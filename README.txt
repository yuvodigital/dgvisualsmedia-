ERIK BERG — FOTO, FILM OCH SPORT

ÖPPNA PROJEKTET I VS CODE

1. Packa upp ZIP-filen.
2. Öppna hela mappen erik-berg-calendly i VS Code.
3. Öppna index.html med Live Server eller direkt i webbläsaren.
4. Behåll index.html, style.css och script.js i samma mapp.

BILDER

Lägg kundens bilder i mappen images och använd exakt dessa namn:

- event.jpg
- portrait.jpg
- lifestyle.jpg
- sport.jpg
- sport-1.jpg
- sport-2.jpg
- sport-3.jpg
- sport-4.jpg
- sport-5.jpg
- sport-6.jpg

SPORTSEKTIONEN använder sport-1.jpg till sport-6.jpg.

VIDEO

Lägg MP4-filer i mappen videos och använd exakt dessa namn:

- showreel.mp4
- event.mp4
- lifestyle.mp4
- sport.mp4
- hisingsboll.mp4

Om en video inte har lagts in ännu visas dess posterbild i stället.

KOPPLA CALENDLY

Öppna script.js och hitta:

const CALENDLY_URL = "https://calendly.com/DIN-CALENDLY-LANK";

Byt länken mot fotografens riktiga Calendly-länk, exempel:

const CALENDLY_URL = "https://calendly.com/erikberg/fotografering";

Alla knappar med klassen js-book öppnar sedan Calendly automatiskt.
